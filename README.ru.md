# Привет

**Network & Platform Engineer**

Инфраструктура операторов связи · Частные облака · Linux · Автоматизация · Observability

Работаю в телекоммуникационной отрасли: проектирую, разворачиваю и сопровождаю сетевую и серверную инфраструктуру интернет-провайдеров и операторов мобильной связи.

Моя зона ответственности охватывает весь жизненный цикл инфраструктуры — от физических серверов, сетей и виртуализации до эксплуатации production-систем, наблюдаемости, автоматизации и восстановления после аварий.

## Инженерные компетенции

- **Network Engineering** — инфраструктура операторских сетей, сетевая архитектура, диагностика и эксплуатация.
- **Infrastructure & Platform Engineering** — физические серверы, Linux, частные облака, OpenStack, Proxmox VE, виртуализация и миграция сервисов.
- **DNS Infrastructure** — развёртывание, настройка, мониторинг и эксплуатация рекурсивных DNS-сервисов.
- **Observability Engineering** — инфраструктура мониторинга, собственные экспортёры, коллекторы телеметрии, шаблоны мониторинга, дашборды и алертинг.
- **Databases** — развёртывание, администрирование, резервное копирование, восстановление и интеграция баз данных с инфраструктурными сервисами.
- **DevOps** — Kubernetes, Terraform, Infrastructure as Code и CI/CD-пайплайны.
- **Engineering Automation** — разработка внутренних инструментов и платформ для решения эксплуатационных задач и автоматизации повторяющихся инженерных операций.
- **Incident Management** — диагностика сложных production-инцидентов, восстановление сервисов, анализ первопричин, postmortem и техническая документация.

## Инженерные проекты

### [Production Private Cloud & DNS Infrastructure](projects/private-cloud-dns-observability.md)

Спроектировал и развернул многонодовое частное облако OpenStack на базе Kolla-Ansible для размещения рекурсивной DNS-инфраструктуры мобильного оператора с абонентской базой около 100 000 человек.

В рамках проекта занимался развёртыванием инфраструктуры, сетевой интеграцией, настройкой резолверов Unbound, сбором собственных метрик, Prometheus, дашбордами Grafana и алертингом.

Впоследствии перенёс DNS-сервисы с OpenStack на Proxmox VE.

**Технологии:** OpenStack · Kolla-Ansible · Proxmox VE · Linux · Unbound · Prometheus · Grafana

### [OSS Control Center](https://github.com/codexhtb/oss-control-center)

Внутренняя операционная платформа интернет-провайдера, объединяющая техническую поддержку, сетевую диагностику и инженерные рабочие процессы.

Проект охватывает весь комплекс работ: от подготовки физических серверов, виртуализации, инфраструктуры баз данных и развёртывания мониторинга до архитектуры и разработки приложения.

Платформа объединяет NetUP UTM5, LibreNMS, диагностику абонентских подключений, мониторинг EPON/GPON, обработку заявок, работу выездных специалистов, контрольный обзвон и внутреннюю коммуникацию команды.

[Архитектура и технический разбор проекта](https://github.com/codexhtb/oss-control-center/blob/main/docs/portfolio-case-study.md)

**Технологии:** Linux · Proxmox VE · FastAPI · React · TypeScript · PostgreSQL · MariaDB · Docker · LibreNMS

### [Pulse — DNS Observability](https://github.com/codexhtb/pulse)

Self-hosted платформа наблюдаемости DNS-инфраструктуры на базе Unbound.

Pulse обеспечивает наблюдаемость на уровне отдельных DNS-транзакций с помощью DNStap-телеметрии, конвейера сбора и корреляции на Go, персистентного состояния корреляции и хранилища ClickHouse.

Возможности включают анализ DNS-трафика в реальном времени, корреляцию запросов и ответов, исследование задержек, сравнение резолверов, обнаружение аномалий и независимый DNS control plane.

Платформа работает вне критического пути обработки DNS-запросов.

**Технологии:** Go · DNStap · ClickHouse · Unbound · React · TypeScript · Docker

### [DNS NOC Bot](https://github.com/codexhtb/dns-noc-bot)

Telegram-инструмент для эксплуатации production DNS-инфраструктуры. Интеграция с Prometheus обеспечивает проверку состояния резолверов, анализ трафика, метрики производительности, активные алерты и статистику Linux conntrack.

**Технологии:** Python · Prometheus · Telegram Bot API · Linux

### [CLIRace][https://github.com/codexhtb/clirace](https://clirace.fun/)

Интерактивная платформа для изучения Linux и DevOps с настоящим терминалом, практическими заданиями и многопользовательскими сессиями в изолированных rootless Docker-контейнерах.

**Технологии:** TypeScript · Fastify · React · PostgreSQL · Redis · Docker · WebSocket

## Расследование инцидентов и технические публикации

### [Huawei SANEX9510 — Production Incident Postmortem](https://habr.com/ru/articles/1101712/)

Опубликованный технический разбор восстановления критической телекоммуникационной OSS-платформы после десяти месяцев простоя.

Выявил и устранил семь независимых неисправностей в нескольких компонентах системы, включая проблемы legacy TLS/PKI, Java keystores, криптографической совместимости и соединений с Sybase IQ.

Восстановил систему за три дня без перезагрузки серверов и перезапуска базы данных.

Статья опубликована на Хабре.

Помимо публичных технических публикаций, веду внутреннюю документацию инфраструктуры, эксплуатационные инструкции, процедуры восстановления и postmortem критических production-систем в BookStack.
